Kết nối điện thoại Android bằng cáp USB để bắt đầu.

Chưa thấy điện thoại của bạn?

Mở phần Tùy chọn nhà phát triển (Developer options) trên điện thoại, bật Gỡ lỗi USB (USB debugging), rồi cắm cáp USB có hỗ trợ truyền dữ liệu. Nếu điện thoại hỏi “Allow USB debugging”, hãy chọn cho phép.

Cùng bắt đầu nhé
Bạn không cần nhớ lệnh. Chọn công cụ, điền thông tin và nhấn nút. Phần hướng dẫn dưới đây sẽ giúp bạn chuẩn bị.
1
Kết nối điện thoại
Dùng cáp USB có hỗ trợ truyền dữ liệu. Bật Gỡ lỗi USB (USB debugging) trong Tùy chọn nhà phát triển trên điện thoại và cho phép kết nối khi được hỏi.
Cài công cụ kết nối nếu chưa có
Cần Android SDK Platform Tools (ADB). Nếu chưa được tự động nhận diện, vào Cài đặt để chọn thư mục Android SDK. Bạn có thể nhờ nhóm kỹ thuật hỗ trợ bước này.
2
Theo dõi hoạt động ứng dụng
Nhập mã ứng dụng (package name), chọn điện thoại và nhấn Bật theo dõi. Bạn có thể lấy mã từ nhóm phát triển. Để xem các sự kiện, mở Firebase → Analytics → DebugView. Khi xong, nhấn Tắt theo dõi.
3
Gửi file hỗ trợ đọc báo lỗi
Xin file symbols.zip từ nhóm phát triển, kiểm tra mã ứng dụng Firebase, chọn file và nhấn Gửi file. Kết quả sẽ hiển thị ngay bên dưới khi quá trình hoàn tất.
Chuẩn bị Firebase cho lần đầu sử dụng
Cần Firebase CLI và tài khoản có quyền với ứng dụng. Cài bằng npm install -g firebase-tools, sau đó đăng nhập bằng firebase login trong terminal. Bạn có thể nhờ nhóm kỹ thuật cài giúp.
4
Mở công cụ theo dõi thiết bị
Nhấn Mở theo dõi thiết bị để mở Android Monitor đã cài trên máy. Nếu chọn quyền quản trị viên, Windows có thể yêu cầu bạn xác nhận.
Yêu cầu cài đặt Android Monitor
Cần Windows, Android SDK Tools cũ có tools/monitor.bat và Java tương thích. Android SDK mới đã bỏ công cụ này. Chọn thư mục SDK phù hợp trong Cài đặt hoặc nhờ nhóm kỹ thuật hỗ trợ.
